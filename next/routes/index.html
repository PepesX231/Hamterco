Route กับแพ็กเกจต่างกันยังไง

Route คือทักษะหนึ่งเรื่อง เลือกเรียนแยกได้ทีละเส้น ส่วนแพ็กเกจรวม 3 Route ที่ต่อกันจนได้ชิ้นงานหนึ่งชิ้นตามเป้าหมาย เช่น เว็บไว้ใส่พอร์ต หรือโปรเจกต์ส่งแข่ง

ราคาที่เห็นเป็นราคาจริงไหม

ตอนนี้ราคาของ Route และแพ็กเกจเป็นราคาตัวอย่าง ราคาจริงและรอบที่เปิดเช็กได้ใน LINE ก่อนสมัคร

ต้องมีพื้นฐานก่อนไหม

แพ็กเกจ First Build ตั้งใจไว้สำหรับคนที่ยังไม่เคยทำโปรเจกต์ ส่วนพื้นฐานของแต่ละ Route ทีมกำลังสรุป ถ้าไม่แน่ใจ ทัก LINE ให้ทีมช่วยเลือกได้

เรียนที่ไหน กี่ครั้ง

รายละเอียดเวลาและสถานที่ของแต่ละ Route ทีมกำลังสรุป ทัก LINE เพื่อถามรอบที่เปิดอยู่

Port Express และ Project Build Skill เป็นแพ็กเกจไหม

ไม่ใช่ ทั้งสองเป็นโปรแกรมเต็มที่มีเงื่อนไขของตัวเอง Port Express เรียน 2 เดือน ราคา 5,990 บาท ส่วน Project Build Skill เป็นโปรแกรม 12 เดือน ราคา 19,990 บาท

สมัครยังไง

  1. เลือก Route หรือแพ็กเกจดูชิ้นงานที่จะได้ทำ เวลา และราคา
  2. ทัก LINE บอกชื่อที่เลือกทีมตอบรอบที่เปิด ราคาจริง และเวลาเรียน
  3. ยืนยันรอบที่จะเรียนทีมแจ้งวันเริ่มและวิธีชำระเงิน
